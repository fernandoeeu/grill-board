# 0012 — Public GitHub repo with MIT license

- **Date:** 2026-08-08
- **Status:** Accepted
- **Decided by:** Owner (grill session)

## Context

The app needs a public home for source code, issues, and community contributions.

## Decision

Host the public repo at `github.com/fernandodudata/grill-board` with an MIT `LICENSE` file at the root.

## Consequences

- The repo name matches the npm package name, reducing confusion.
- MIT license is permissive and widely understood.
- The current repo (simple-visual-grill-app) may be archived or redirected once the public repo is live.
