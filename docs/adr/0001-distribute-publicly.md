# 0001 — Distribute the Grill Board publicly under MIT

- **Date:** 2026-08-08
- **Status:** Superseded by 0013
- **Decided by:** Owner (grill session)

## Context

The Grill Board app is a standalone tool for running structured grill sessions. The decision-tool (Synara) is a separate, private product. There is value in letting the community use the grill flow independently.

## Decision

Distribute this repo (simple-visual-grill-app) publicly as an MIT-licensed open-source project. The decision-tool remains private and is not affected.

## Consequences

- The repo must contain no proprietary code, secrets, or references to private infrastructure.
- MIT license allows unrestricted use, modification, and redistribution.
- Maintenance burden shifts to include community issues and contributions.
